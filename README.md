# Anexo Interactivo — Evaluación de Modelos MLP (Tarea 2)

Página estática para GitHub Pages con las tablas de validación, métricas en prueba (comparadas con Chicco & Jurman, 2020), curvas de aprendizaje en alta resolución y matrices de confusión de las configuraciones C1–C4.

## Estructura
- `index.html`: Sitio web interactivo (sin dependencias de compilación).
- `images/`: Curvas de aprendizaje de C1, C2, C3 y C4.

## Despliegue en GitHub Pages
1. Sube estos archivos a un repositorio público en GitHub.
2. Ve a **Settings → Pages**.
3. En **Branch**, selecciona `main` y carpeta `/ (root)`, luego haz clic en **Save**.
